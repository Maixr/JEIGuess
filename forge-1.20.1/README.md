# JEI Guess（猜你想搜）

点击 JEI 搜索框，弹出「最近搜索 + 猜你想搜」——像浏览器地址栏一样，点击即搜。

适用于 **Minecraft 1.20.1 / Forge**，为 **JEI 15.x** 设计（可选依赖，未装 JEI 时本体不报错、功能静默禁用）。

> 与 JEI 官方及其作者（mezz）无隶属关系 / Not affiliated with JEI or its author (mezz).

## 候选来源

**第一页（混合页）默认 8 条**：3 最近 + 3 任务 + 1 推荐 + 1 常搜。
★ 如果伊甸核心机正在要求提交物品，会再多一条【推荐·伊甸】，这一页就是 **9 条**。

**往后滚是一个来源一页**（滚轮 / `←→` / `PageUp·PageDown`）：
【收藏】【最近】【任务】【常搜】【聊天】【热词】【推荐】各占一整页，条目多就继续分块（`最近 1/3`、`最近 2/3`…）。
所以候选不再只有 7 条 —— 第一页是"猜测"，往后翻就是"全部家底"。

| 来源 | 混合页条数 | 是怎么来的 |
|---|---|---|
| 【收藏】 | 2 | 右键加星的词，**永远排最上面**（先占位） |
| 【最近】 | 3 | 你搜过的词（含 JEI 自带历史） |
| 【任务】 | 3 | FTB Quests 里**最近查看的**未完成任务 → 查看次数最多的 → 已开工的 → 其他可做的（**鼠标悬停那一行**会显示它来自哪个任务） |
| 【常搜】 | 1 | 搜索次数最多的词，右侧显示 `x12` |
| 【推荐】 | 1 | 配置文件里的推荐词池随机抽（整页时列出全部） |
| 【上次】 | — | ★ 上次搜这个词之后你**点开过的那件物品**（只在输入时出现） |
| 【聊天】 | 0 | 聊天里被提到的物品（默认只在自己的整页里出现） |
| 【热词】 | 2 | 全服搜索热词（需服务端也装本 mod，见下） |

顺序与配额全部可在配置文件里改。

## 关键设计：显示名 ≠ 搜索词

JEI 搜中文 mod 名（如「无尽贪婪」）是什么都搜不到的——必须搜 `@avaritia`。本 mod 自动做这层翻译：

- **mod 名 → `@modid`**：★ 不再依赖手写映射表，而是**只读 mod 自己的创造模式标签页**——取标签页的中文名（「机械动力」），统计页内物品的命名空间（`create`），自动得到 `机械动力 → @create`。**任何整合包、任何语言都通用**。
  原版标签页（建筑方块 / 自然方块 / 工具与实用物品…）三层过滤掉：类型必须是 CATEGORY、注册名不能是 `minecraft` 命名空间、页内物品命名空间也不能是 `minecraft`。
- **标签名 → `#tag`**：★ 直接**从真实标签注册表推导**——输入「剑」，先按物品名找到几把剑，再看它们都在哪些标签里，于是得到 `剑 (#c:swords)` 这类候选（输 `sword` 也能直接命中）。
  标签的中文显示名来自内置的**英文路径 → 中文**表（`swords → 剑`、`ingots → 锭` …），**不硬造翻译**，查不到就显示英文路径。
  想补翻译：改 `config/jeiguess-tags.json`（格式 `{"剑": "#swords"}`），重启即生效 —— 欢迎社区往这张表里加。
- **全都支持拼音**：物品名、mod 名、标签名都能用拼音/首字母输入（`jxdl → 机械动力`、`stjsq → 实体加速器`，需装通用拼音搜索 JEC）。
- **兜底修正**：点击前先探测这个词在 JEI 里有没有结果；没有才依次尝试 `@modid` → `#tag` → modid 归一化 → 物品名模糊匹配。
  ★ 所以能搜到的词**不会被乱改**（「石头」就是搜石头，不会因为存在 `#stone` 就被改写）。

## 交互（★ 每个键只有一个功能）

| 操作 | 效果 |
|---|---|
| 左键 / Enter | 搜索（Enter 搜的是**鼠标悬停的那条**） |
| 右键 | 收藏 / 取消收藏（★ 金色置顶） |
| Shift + 右键 | 从历史 / 聊天池里删掉这一条 |
| 鼠标滚轮 | 翻页（鼠标在面板上时） |
| 鼠标悬停 | 即选中（所以**不需要**占用 ↑/↓ —— 它们完全留给 JEI） |
| 标题 [?] | 悬停显示全部操作说明 |
| 标题 [全部] | 点击切换来源筛选 |
| `Tab` | **只做一件事**：接受灰字补全（没有补全时完全不拦截） |
| `Ctrl + Tab` | 切换来源筛选 |
| `←` / `→` | 翻页，但**只在搜索框为空时**才抢；有文字时交还给 JEI 移动光标 |
| `PageUp` / `PageDown` | 任何时候都能翻页（键位可在配置里改） |
| `Enter` / `Esc` | 确认 / 关闭 |

**为什么这样分**：JEI 自己要用 ↑/↓ 和 ←/→ 编辑文本，任何"抢占式"绑定都会有人被坑。本 mod 的策略是——
① 能用鼠标表达的全部用鼠标（收藏 / 删除 / 翻页 / 筛选都不占键）；
② 键盘只在"抢了也不会影响打字"的语境下生效，且一个键只干一件事；
③ 翻页键可在配置里改成任意 GLFW 键名；④ 不注册任何全局快捷键。

## 聊天物品链接

聊天里出现的**物品中文名 / 物品 id / 标签 / 模组名**会自动加下划线，点击：

- **默认** → 打开合成表
- **Shift + 点击** → 打开用途表（相当于按 U）
- **Ctrl + 点击** → 复制物品 id

修饰键是在**点击的那一刻**读键盘状态的，所以不需要任何按键绑定，也不会撞键。

其它细节：一句话里同时出现多个可点击项时**优先匹配更长的词**；**不覆盖**别人已有的点击事件（KubeJS `/kubejs hand` 的「点击复制 ID」保持可用）；点击走本地处理，**不会把命令发到服务器**。

## 其它

- **灰色补全**：搜索框里灰色显示补全词，`Tab` 接受。
- **纠错**：「钻石搞」→ 提示「你是不是想搜：钻石镐」（编辑距离 ≤ 2）。
- **语法提示**：输入 `@` 列 mod（带 `@modid`），输入 `#` 列标签。
- **任务书接管**：在 FTB 任务书里点开一个任务，回到 JEI 点搜索框，【任务】里就是它要的东西（**把鼠标停在那一行**会显示它来自哪个任务）；`/jeiguess quest` 也能直接搜。
  推荐判据：**前置任务全部满足（用 FTB 自己的 areDependenciesComplete 判定）+ 任务本体未完成 + 最近查看过的优先**。
- **导出**：`/jeiguess export` 把搜索历史导成 CSV。

## 命令（全部是客户端命令）

| 命令 | 作用 |
|---|---|
| `/jeiguess quest` | 显示并搜索"任务书里正在看的那个任务"所需物品 |
| `/jeiguess export` | 导出 `config/jeiguess-export-<时间>.csv` |
| `/jeiguess ban <词>` / `unban <词\|all>` | 屏蔽 / 恢复候选 |
| `/jeiguess fav <词>` | 收藏 / 取消收藏 |
| `/jeiguess hot` | 查看当前服务端热词 |
| `/jeiguess stats` | 统计信息 |

## 服务端热词（可选）

服务端也装上本 mod 后（并开启 `serverconfig/jeiguess-server.toml`），会把全服搜索热词推送给客户端，显示为【热词】。

★ 安全性：客户端**只有在收到过服务端的包之后**才会回传数据，服务端推送前也会确认对方装了本 mod ——
服务端没装 / 客户端没装，双方都不会产生任何"未注册频道"的报错。

## 配置文件

`config/jeiguess-client.toml`（客户端）、`serverconfig/jeiguess-server.toml`（服务端）

配置文件里所有开关都在注释里写清楚了，常用的几个：

- `[suggest.quota]` 各来源条数
- `[suggest.behavior]` `ghostText` / `correction` / `syntaxHints` / `hoverSelects` / `pagingKeys` / `pagingNeedsEmptyInput` / `chatLinkModifierKeys`
- `[suggest.words]` `recommendWords` 推荐词池、`modAliases` 手动映射（一般不需要）

数据文件 `config/jeiguess_history.json`（搜索历史 / 收藏 / 点选记录 / 任务浏览记录），退出世界时落盘。

## 兼容性与性能

- **全程反射调用**：JEI / FTB Quests / JEC / MaixrCore 任何一个没装或版本结构不同，对应子功能静默跳过，**不会崩游戏**
- **分帧构建索引**：约 2 万个物品名按「首字符」分桶，每 tick 只建一小批
- 每次按键最多一次全表扫描（标签推导复用物品名匹配的结果，不重复扫）
- 客户端功能全部在 `Dist.CLIENT` 类里，专用服务端只加载热词相关代码
