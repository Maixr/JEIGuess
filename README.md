# JEI Guess（猜你想搜）

把 **JEI 的搜索框**变成浏览器地址栏：点一下，弹出你最可能要搜的东西，点一条即搜。

## 它做什么
###当然它是完全可以自由配置的

| 来源 | 混合页条数 | 说明 |
|---|---|---|
| 【收藏】 | 2 | 右键加星的词，永远排最上面 |
| 【最近】 | 3 | 你搜过的词（合并 JEI 自带历史，最新在前） |
| 【任务】 | 3 | FTB Quests 里**最近查看的**未完成任务所需物品 |
| 【常搜】 | 1 | 搜索次数最多的词 |
| 【推荐】 | 1 | 配置里的推荐词池随机抽 |
| 【上次】 | — | 上次搜这个词之后**你点开过的那件物品**（仅输入时出现） |
| 【聊天】 | 0 | 聊天里被提到的物品（有独立整页） |
| 【热词】 | 2 | 全服搜索热词（需服务端也装本 mod） |

**第一页默认 8 条**；如果在整合包《弧光计划·裂隙重生中》伊甸核心机正在要求提交物品时会多一条【推荐·伊甸】（9 条）。
**往后滚是一个来源一整页**（`收藏` / `最近` / `任务` / `常搜` / `聊天` / `热词` / `推荐`），条目多就继续分块 —— 所以候选远不止 7 条。

## 关键设计

**1. 显示名 ≠ 搜索词。** JEI 搜中文 mod 名（「无尽贪婪」）什么都搜不到，必须搜 `@avaritia`。本 mod 自动翻译：

- **中文 mod 名 → `@modid`**：★ 不靠手写对照表，而是**读创造模式标签页推导** —— 取标签页中文名（「机械动力」）+ 统计页内物品的命名空间（`create`），自动得到映射。**任何整合包、任何语言都通用**。
  原版标签页三层过滤：类型必须是 CATEGORY、注册名不能是 `minecraft` 命名空间、页内物品命名空间也不能是 `minecraft`。
- **标签名 → `#tag`**：★ 从**真实标签注册表**推导 —— 输入「剑」，先按物品名找到几把剑，再看它们都在哪些标签里，得出 `剑 (#c:swords)`。中文显示名来自内置的「英文路径 → 中文」表，查不到就显示英文路径，**不硬造翻译**。
- **兜底修正**：点击前先探测这个词在 JEI 里有没有结果，没有才依次尝试 `@modid` → `#tag` → modid 归一化 → 物品名模糊匹配。能搜到的词**不会被乱改**。

**2. 全都能用拼音。** 物品名、mod 名、标签名、`@`/`#` 语法提示，都支持拼音与首字母（`jxdl → 机械动力`、`stjsq → 实体加速器`，需装通用拼音搜索 JEC）。

**3. 按键不冲突。** 每个键只有一个功能；能用鼠标表达的全部用鼠标。

| 操作 | 效果 |
|---|---|
| 左键 / Enter | 搜索（Enter 搜鼠标悬停那条） |
| 右键 | 收藏 / 取消收藏 |
| Shift + 右键 | 从历史 / 聊天池删掉 |
| 鼠标滚轮 | 翻页 |
| 悬停 | 即选中（不占 ↑/↓，全留给 JEI） |
| 标题 [ ? ] | 悬停看操作说明 |
| `Tab` | 接受灰字补全（没有补全时完全不拦截） |
| `Ctrl+Tab` | 换页 / 切换来源筛选 |
| `←` / `→` | 翻页，**只在搜索框为空时**才抢（有文字时还给 JEI 移动光标） |
| `PageUp`/`PageDown` | 任何时候都能翻页 |

**4. 聊天物品链接。** 聊天里的物品名/id/标签/模组名加下划线，**默认点击查合成表、Shift+点击查用途表、Ctrl+点击复制物品 id**。优先匹配更长的词；**不覆盖**别人已有的点击事件（KubeJS `/kubejs hand` 的「点击复制 ID」照常可用）；点击走本地处理，**不会把命令发到服务器**。

**5. 其它。** 灰色补全、拼写纠错（「钻石搞」→ 你是不是想搜「钻石镐」）、`@`/`#` 语法提示、任务书界面接管、可选的服务端全服热词、搜索历史导出 CSV。

## 支持版本

| 版本 | MC | 加载器 | 状态 |
|---|---|---|---|
| [`forge-1.20.1`](forge-1.20.1) | 1.20.1 | Forge 47.x | ✅ 已实测 |

JEI 是**可选**依赖：没装 JEI 时本体不报错、功能静默禁用。所有第三方交互（JEI / FTB Quests / JEC / KubeJS）**全程反射**，任何一个缺失或版本结构变化都只静默跳过对应子功能，**不会崩游戏**。

## 构建

**1.20.1 Forge**（Gradle 8.9 + JDK 17）：

```bash
cd forge-1.20.1
./gradlew build
# 产物 build/libs/JEIGuess-<版本>.jar
```

**1.21.1 NeoForge**：见 [`neoforge-1.21.1`](neoforge-1.21.1)。该目录当前是手工 javac 构建（开发机无网络，Gradle 插件无法离线解析），命令写在目录内的 README-PORT.md 里。
