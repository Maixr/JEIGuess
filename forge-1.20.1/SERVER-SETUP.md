# JEI Guess 服务端安装说明（全服热词）

> 服务端**只需要**这一个 jar。不需要 JEI、不需要 FTB Quests、不需要任何前置。
> 不装也能玩——不装的话客户端全程沉默，什么都不会发生。

## 一、装什么

把和客户端**同一个** `JEIGuess-<版本>.jar` 放进服务端 `mods/` 目录即可。

- 服务端版本：Forge 1.20.1（和客户端一致）
- 服务端不需要装 JEI：本 mod 在服务端只做"统计搜索词"这一件事

## 二、三步走

1. 放 jar 进 `mods/`
2. **启动一次服务器**（会自动生成配置文件）
3. 检查/修改下面的配置，然后重启服务器

## 三、服务端配置

`serverconfig/jeiguess-server.toml`（每个存档世界一份，首次启动自动生成）

```toml
[hotwords]
    # 是否启用全服热词
    enabled = true
    # 同步多少个热词给客户端
    topCount = 5
    # 多久推送一次（秒）
    pushIntervalSeconds = 300
@@@

## 四、客户端侧

`config/jeiguess-client.toml`：

@@@toml
[suggest.server]
    # 客户端是否显示 / 上报热词（默认开；关掉就完全退出这个功能）
    hotWords = true
@@@

## 五、数据流

@@@
玩家在 JEI 里搜一个词
   ↓ 停手 1.5 秒（防抖，不会逐字上报）
客户端上报一个词 ──► 服务端累计计数（内存）
                          ↓ 每 pushIntervalSeconds 秒
                   推送给「装了本 mod」的客户端 ──► 显示为【热词】候选
@@@

## 六、为什么不会出事（安全设计）

| 设计 | 作用 |
|---|---|
| 客户端**先收到服务端的包**才回传 | 服务端没装 mod 时，客户端一个字都不发 |
| 服务端推送前用 `isRemotePresent()` 确认 | **绝不会**往原版/未装 mod 的客户端发包 |
| 频道版本判定接受 `ACCEPTVANILLA` | 装与不装都不会因为"版本不匹配"被踢下线 |
| 上报内容只有搜索词字符串（≤32 字符） | 不含玩家名、坐标、背包等任何隐私数据 |

**玩家没装 mod 会怎样**：完全无影响，收不到任何包。

## 七、怎么验证

- 客户端输入 `/jeiguess hot` → 显示当前热词排行榜
- 客户端输入 `/jeiguess stats` → 统计信息
- 服务端控制台搜 `[猜你想搜]` → 应能看到热词相关日志
- 客户端日志搜 `收到服务端热词` → 出现这行说明链路通了

## 八、已知限制（v1）

1. 热词统计是**内存态**，服务器重启后清零
2. 单人游戏不统计也不推送（只有你自己看，纯噪音）
3. 只记录"停手 1.5 秒后"的那个词，逐字输入不会被记录
4. 关掉本功能：服务端 `enabled = false`，或客户端 `hotWords = false`
