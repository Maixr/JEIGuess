# JEI Guess 外挂词库指南

> 适用版本：**v0.7.0 及以上**
> 一句话：把三个 JSON 放进 `config/`，改完在游戏里输入 `/jeiguess reload`。

---

## 1. 三种纠正

| 类型 | 文件 | 解决什么 | 例子 |
|---|---|---|---|
| **整体纠正** | `jeiguess-whole.json` | 整词是另一个东西 | 鞋子 → 靴子 |
| **部分纠正** | `jeiguess-part.json` | 只错了一部分 | 钻石高 → 钻石镐 |
| **拼音纠正** | `jeiguess-pinyin.json` | 拼音拼法不对 | luse → lvse |

三者都会在面板顶部显示「你是不是想搜：XXX」，点一下直接搜。

**默认触发条件：当前搜索结果少于 3 条。**
整体纠正里的 `always` 段可以无视这个限制（见第 3 节）。

---

## 2. 文件在哪

首次启动后，`config/` 目录下会自动生成三个带示例的文件：

```
.minecraft/config/jeiguess-whole.json
.minecraft/config/jeiguess-part.json
.minecraft/config/jeiguess-pinyin.json
```

删掉也能正常运行（只是没有自定义规则）。示例里的条目都是**真能搜到东西**的，可以直接照抄改。

> 旧版留下的 `config/jeiguess-aliases.json` 继续有效，会被当成「整体纠正」。

---

## 3. 整体纠正（whole）

```json
{
  "rules": {
    "鞋子": "靴子",
    "包包": "潜影盒"
  },
  "always": {
    "岩浆": "熔岩"
  }
}
```

- **键** = 玩家会输入的内容，**整词匹配**（输入"钻石高"不会触发"高"这条）。
- **值** = 目标词。可以写精确物品名，也可以写"能搜到的词"：
  `鞋子 → 靴子` 虽然游戏里没有叫"靴子"的物品，但能搜出所有靴子，所以有效。
- **always 段** = **无论当前搜到多少条都提示**。适合"玩家很可能打错、但游戏里恰好有同名物品"的情况
  （岩浆块是官方物品，所以"岩浆"这条必须整词匹配 + 强制提示）。
- **冲突**：内置表和外挂表写了同一条但目标不同时，**两条都会显示**（面板上是两行），由你自己判断。

也支持最简写法（整个对象就是规则，没有 always）：

```json
{ "鞋子": "靴子" }
```

---

## 4. 部分纠正（part）

```json
{
  "rules": {
    "铲": "锹",
    "稿": "镐"
  }
}
```

规则：**输入里包含左边的词就替换成右边**。

- **最长优先**：同时有 `铲` 和 `铲子` 时，先匹配长的。
- **每条只换一次**：同一条规则不会反复替换。
- 替换后的词必须**能搜到东西**，否则这条不生效。

### 常见坑

**不要用高频单字做部分纠正。** 例如 `高 → 镐`：

- `钻石高` → `钻石镐` ✅ 正确
- `高炉` → `镐炉` ❌ 变成不存在的词，校验会拦住它，但这条规则也就废了一半

能用词组就别用单字：`钻石高 → 钻石镐` 比 `高 → 镐` 安全得多。

---

## 5. 拼音纠正（pinyin）

```json
{
  "rules": {
    "luse": "lvse"
  }
}
```

- 只对**纯字母输入**生效（中文输入不会走这一档）。
- **内置 ü 互换**已经覆盖：`lu↔lv`、`nu↔nv`、`lue↔lve`、`nue↔nve`、`lyu↔lv`、`nyu↔nv`。
  也就是说 `luse → lvse` 不写这条规则也会自动尝试。
- **原输入本来就能搜到时不会提示**（JEC 已兼容 luse/lvse，再提示就是噪音）。
- 结果必须能拼音匹配到物品，否则不生效。

---

## 6. 让改动生效

在游戏里输入：

```
/jeiguess reload
```

聊天栏会回显当前词库条数，例如：

```
词库已重载：整体 160 条，部分 3 条，拼音 1 条，强制 2 条
```

**不需要重启游戏。**

---

## 7. 强校验：写错了会怎样

目标必须**真能搜到东西**（至少 1 件物品），否则这条规则会被**整条忽略**，只在日志里留一句。

会失败的情况：

| 情况 | 结果 |
|---|---|
| 目标写错字（"马铃薯"写成"马玲署"） | 忽略，日志提示 |
| 目标指向整合包没装的 mod | 忽略 |
| 目标用了英文名（"potato"） | 忽略（游戏里搜的是中文名） |
| 目标写 `@create` 这类 mod 前缀 | 忽略（校验查的是物品名，不是 mod 前缀） |

这是刻意的：**宁可没有提示，也不给一个点进去空白的候选。**

---

## 8. 优先级

```
整体纠正 → 部分纠正 → 拼音纠正 → 同音单字 → 首字母 → 同音字替换
└──────── 你的词库（明确规则）────────┘ └──────── 内置猜测（启发式）────────┘
```

**你写的规则永远先跑。** 这是 v0.6.7 的教训：明确规则排在"猜"后面时，
「钻石铲」会被首字母档抢成「钻石锄」。

---

## 9. 写词库的三条铁律

1. **方向别反**：键是**玩家打的**，值是**游戏里的**。
   `土豆 → 马铃薯` ✅　`马铃薯 → 土豆` ❌
2. **官方名别当键**：圆石、木棍、工作台本身就是官方名，写成键会把**正确**的搜索改掉。
3. **先验证再写**：在 JEI 里搜一下目标词，能出东西再写进词库。

---

## 10. 排查

看日志（`logs/latest.log`）里的关键词：

```
[猜你想搜] 词库已加载：整体 158 内置/2 外挂，部分 1 内置/2 外挂，拼音 0 内置/1 外挂，强制 2 条
[猜你想搜] 已生成词库示例：jeiguess-whole.json
[猜你想搜] 载入词库失败 jeiguess-part.json: ...
```

**提示没出现**，按顺序检查：

1. 搜索结果是不是 ≥3 条？（默认不提示；要强制就放 `always`）
2. 跑过 `/jeiguess reload` 吗？
3. 目标能搜到物品吗？（第 7 节）
4. 输入是不是整词匹配？（整体纠正不做子串匹配）

---

## 11. 配置界面（1.21.1）

**模组菜单 → JEI Guess → 配置**，NeoForge 会自动生成完整界面（读取 mod 自己的配置项）。

1.20.1 (Forge) 暂未接入这个界面，请直接改 `config/jeiguess-client.toml`。

## 12. 完整示例

`config/jeiguess-whole.json`
```json
{
  "rules": {
    "鞋子": "靴子",
    "包包": "潜影盒",
    "工作服": "皮革外套"
  },
  "always": {
    "岩浆": "熔岩"
  }
}
```

`config/jeiguess-part.json`
```json
{
  "rules": {
    "铲": "锹",
    "钻石高": "钻石镐"
  }
}
```

`config/jeiguess-pinyin.json`
```json
{
  "rules": {
    "luse": "lvse"
  }
}
```
