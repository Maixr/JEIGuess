JEI Guess 外挂词库指南
适用版本：v0.7.0 及以上
作者：Maixr

============================================================
太长不看
============================================================

把三个 JSON 文件放进 .minecraft/config 目录，改完在游戏里输入
/jeiguess reload，立刻生效，不用重启。

三种文件分别管三件事：
  jeiguess-whole.json    整体纠正   鞋子 → 靴子
  jeiguess-part.json     部分纠正   钻石高 → 钻石镐
  jeiguess-pinyin.json   拼音纠正   luse → lvse

首次启动会自动生成这三个文件，里面带示例，照着改就行。
删掉也不影响游戏运行，只是没有自定义规则。

============================================================
一、三种纠正分别解决什么
============================================================

【整体纠正】
  你打的整个词，游戏里叫另一个名字。
  例：鞋子 → 靴子、包包 → 潜影盒

【部分纠正】
  只有一部分打错了。
  例：钻石高 → 钻石镐、铁铲 → 铁锹

【拼音纠正】
  拼音拼法不对。
  例：luse → lvse

三者都会在面板顶部显示「你是不是想搜：XXX」，点一下直接搜出来。

默认触发条件：当前搜索结果少于 3 条。
整体纠正里的 always 段可以无视这个限制（见第三节）。

============================================================
二、文件在哪
============================================================

.minecraft/config/jeiguess-whole.json
.minecraft/config/jeiguess-part.json
.minecraft/config/jeiguess-pinyin.json

首次启动自动生成，带注释性示例（示例条目都是真能搜到东西的）。
旧版留下的 config/jeiguess-aliases.json 继续有效，会被当成整体纠正。

============================================================
三、整体纠正（whole）
============================================================

文件内容长这样：

{
  "rules": {
    "鞋子": "靴子",
    "包包": "潜影盒"
  },
  "always": {
    "岩浆": "熔岩"
  }
}

规则说明：

1. 键 = 玩家会输入的内容，整词匹配。
   输入"钻石高"不会触发"高"这条规则。

2. 值 = 目标词。可以写精确物品名，也可以写"能搜到的词"。
   鞋子 → 靴子：游戏里没有叫"靴子"的物品，但能搜出所有靴子，所以有效。

3. always 段 = 无论当前搜到多少条都提示。
   适合"玩家很可能打错、但游戏里恰好有同名物品"的情况。
   例子：岩浆块是官方物品，"岩浆 → 熔岩"这条必须整词匹配 + 强制提示，
   否则打"岩浆块"的人会被带偏。

4. 冲突处理：内置表和外挂表写了同一条但目标不同时，两条都会显示
   （面板上是两行），由你自己判断哪条对。

也支持最简写法（整个对象就是规则，没有 always）：

{ "鞋子": "靴子" }

============================================================
四、部分纠正（part）
============================================================

文件内容长这样：

{
  "rules": {
    "铲": "锹",
    "钻石高": "钻石镐"
  }
}

规则说明：

1. 输入里包含左边的词，就替换成右边。
2. 最长优先：同时有"铲"和"铲子"时，先匹配长的。
3. 每条只换一次：同一条规则不会反复替换。
4. 替换后的词必须能搜到东西，否则这条不生效。

【常见坑】不要用高频单字做部分纠正。
例如"高 → 镐"：
  钻石高 → 钻石镐   正确
  高炉   → 镐炉     错，会变成一个不存在的词

校验会拦住这种坏结果（不会真的把搜索改坏），但这条规则也就废了一半。
能用词组就别用单字：写"钻石高 → 钻石镐"比写"高 → 镐"安全得多。

============================================================
五、拼音纠正（pinyin）
============================================================

文件内容长这样：

{
  "rules": {
    "luse": "lvse"
  }
}

规则说明：

1. 只对纯字母输入生效，中文输入不会走这一档。
2. 内置 ü 互换已经覆盖下面这些，不写规则也会自动尝试：
   lu ↔ lv、nu ↔ nv、lue ↔ lve、nue ↔ nve、lyu ↔ lv、nyu ↔ nv
3. 原输入本来就能搜到时不会提示。
   （JEC 本身兼容 luse 和 lvse，再提示纯属噪音）
4. 结果必须能匹配到物品，否则不生效。

============================================================
六、让改动生效
============================================================

在游戏里输入：

/jeiguess reload

聊天栏会回显当前词库条数，例如：

词库已重载：整体 160 条，部分 3 条，拼音 1 条，强制 2 条

不需要重启游戏。

============================================================
七、强校验：写错了会怎样
============================================================

目标必须真能搜到东西（至少 1 件物品），否则这条规则会被整条忽略，
只在日志里留一句话。

会失败的情况：

  目标写错字（"马铃薯"写成"马玲署"）  → 忽略
  目标指向整合包没装的 mod            → 忽略
  目标用了英文名（"potato"）           → 忽略（游戏里搜的是中文名）
  目标写 @create 这类 mod 前缀         → 忽略（校验查的是物品名）

这是刻意设计的：宁可没有提示，也不给一个点进去空白的候选。

============================================================
八、优先级
============================================================

整体纠正 → 部分纠正 → 拼音纠正 → 同音单字 → 首字母 → 同音字替换

（你的词库，明确规则）        （内置猜测，启发式）

你写的规则永远先跑。
这是 v0.6.7 的教训：明确规则排在"猜"后面时，
"钻石铲"会被首字母档抢成"钻石锄"。

============================================================
九、写词库的三条铁律
============================================================

1. 方向别反。
   键是玩家打的，值是游戏里的。
   土豆 → 马铃薯   对
   马铃薯 → 土豆   错

2. 官方名别当键。
   圆石、木棍、工作台本身就是官方名，写成键会把正确的搜索改掉。

3. 先验证再写。
   在 JEI 里搜一下目标词，能出东西再写进词库。

============================================================
十、排查
============================================================

看 logs/latest.log，搜索关键词：

  [猜你想搜] 词库已加载：整体 158 内置/2 外挂，部分 1 内置/2 外挂，
             拼音 0 内置/1 外挂，强制 2 条
  [猜你想搜] 已生成词库示例：jeiguess-whole.json
  [猜你想搜] 载入词库失败 jeiguess-part.json: ...

提示没出现，按顺序检查：

1. 搜索结果是不是 ≥3 条？（默认不提示，要强制就放 always）
2. 跑过 /jeiguess reload 吗？
3. 目标能搜到物品吗？（看第七节）
4. 输入是不是整词匹配？（整体纠正不做子串匹配）

============================================================
十一、配置界面（1.21.1）
============================================================

模组菜单 → JEI Guess → 配置

NeoForge 会自动生成完整界面，读取 mod 自己的配置项。
1.20.1 (Forge) 暂未接入这个界面，请直接改 config/jeiguess-client.toml。

============================================================
十二、完整示例
============================================================

config/jeiguess-whole.json

{
  "rules": {
    "鞋子": "靴子",
    "包包": "潜影盒",
    "工作服": "皮革外套"
  },
  "always": {
    "岩浆": "熔岩"
  }
}

config/jeiguess-part.json

{
  "rules": {
    "铲": "锹",
    "钻石高": "钻石镐"
  }
}

config/jeiguess-pinyin.json

{
  "rules": {
    "luse": "lvse"
  }
}

============================================================
附：内置词库已经包含的常见纠正（部分）
============================================================

土豆、洋芋、地蛋 → 马铃薯
鹅卵石、卵石 → 圆石
棍子、木棒 → 木棍
合成台、合成桌 → 工作台
砖石 → 钻石
黑耀石 → 黑曜石
萤石 → 荧石
粘土球 → 黏土球
红罗卜 → 胡萝卜
翅膀、滑翔翼 → 鞘翅
复活图腾 → 不死图腾
经验瓶 → 附魔之瓶
光束塔 → 信标
铲 → 锹
岩浆 → 熔岩（强制提示）
稿子 → 镐
会议室 → 黑曜石
钻石稿 → 钻石镐

以上都是「玩家会打的词 → 游戏里的叫法」这个方向。
